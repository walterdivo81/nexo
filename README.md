# NEXO — Frontend demonstrativo

Este pacote contém um protótipo navegável em HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia o ZIP.
2. Abra `index.html` em um navegador.
3. Use o menu superior para navegar pelas páginas.

## Páginas incluídas
- `index.html`: página inicial
- `pages/cadastro.html`: cadastro e dados básicos
- `pages/descobrir.html`: descoberta de perfis
- `pages/perfil.html`: edição de perfil e galeria de seis fotos
- `pages/filtros.html`: filtros de busca
- `pages/matches.html`: matches
- `pages/mensagens.html`: interface de conversas
- `pages/configuracoes.html`: privacidade e segurança
- `pages/admin.html`: painel administrativo demonstrativo

## Limitações importantes
Este é somente o frontend demonstrativo. Não existe backend conectado, autenticação real, upload efetivo, geolocalização, chat persistente, moderação ou banco de dados. Os botões marcados como demonstração exibem avisos. Não use com dados pessoais reais.

A integração de produção exige Supabase, políticas RLS, validação de idade, moderação, consentimento LGPD, proteção de localização e revisão das políticas das lojas.
